Automation Suitability Tool (prototype)

Is light rail automation worth a closer look on your system?

The Automation Suitability Tool (AST) helps an agency check whether a documented need warrants automation, screen an application against essential requirements, weigh its benefits and costs, and leave with a memo-ready recommendation.

Four steps from a documented need to a recommendation

Work through the steps in order on the next page. Each one takes a few minutes and uses information most agencies already have.

1

Define need and context

Describe the problem and where it occurs.

  • Documented need, such as incident history
  • Application under consideration
  • Location and operating environment
  • Countermeasures already in place
2

Screen feasibility

Answer four yes-or-no style questions.

  • Is there a demonstrated need?
  • Do simpler alternatives fall short?
  • Does it fit the operating conditions?
  • Is there a pathway to approvals?
3

Compare benefits and costs

Rate five criteria from 1 to 5.

  • Higher is always more favorable
  • Adjust weights to local priorities
  • Label each rating's evidence
  • Mark missing data as Insufficient
4

Decide next steps

Read the outcome and share the memo.

  • One of four outcomes
  • Reasons behind the result
  • Recommended next steps
  • Memo for leadership and boards

Reading the results

Screening answers and evidence labels

PassThe requirement is met. UnresolvedNeeds to be verified. The application still moves forward, flagged. Not metNo need, or an essential requirement fails. DocumentedRating based on records, data, or evaluations. JudgmentRating based on staff or stakeholder judgment. InsufficientNot enough information. Flagged, never scored.

The four outcomes

Further feasibility analysis

Strong potential; proceed to detailed engineering, cost, and approval studies.

Pilot consideration

Promising, but evidence from comparable settings is limited; pilot with defined measures.

Additional information needed

Key items are unresolved; the tool lists what to obtain.

Longer-term monitoring

Depends on further technology, regulatory, or institutional developments.

If screening finds no need, the result is Not warranted at this time. If an essential requirement fails, the application is Set aside.

When cost or other information is missing, the score is labeled partial and shows the share of criterion weight assessed. Changing weights never offsets an unresolved requirement.
